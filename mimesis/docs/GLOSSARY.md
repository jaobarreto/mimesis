# Glossário do motor

| Termo | Significado no MIMESIS |
|---|---|
| Recuperação | Localizar itens existentes na edição consultada e devolver candidatos identificados. |
| Similaridade lexical | Proximidade entre formas ou distribuições de termos. Pode aproximar frases com intenções opostas. |
| Similaridade semântica | Proximidade de sentido segundo um modelo explícito, como relações entre conceitos. Exige julgamento separado para polissemia e contexto. |
| Intenção | Hipótese revisável sobre o ato comunicativo, por exemplo pedir confirmação. Pode atravessar várias formas lexicais. |
| Inferência | Produção de conclusão a partir de premissas e regra identificadas. A autoridade da conclusão depende de sua origem. |
| Composição procedural | Escolha de estrutura e realização de texto por regras e dados autorizados. Deve preservar o que se sabe e o que falta. |
| Talkset | Unidade curada que liga um conjunto de prompts a respostas válidas sob condições comuns. |
| Candidato e elegibilidade | Um item recuperado é candidato. Para concorrer à saída deve satisfazer idioma, disponibilidade e restrições aplicáveis. |
| Escore, margem e limiar | Escore ordena candidatos no método. Margem mede separação entre famílias. Limiar define evidência mínima para responder. |
| Fallback | Resultado deliberado de abstenção ou esclarecimento acompanhado de motivo. |
| Persona, emoção e memória | Perfil expressivo recebido, estado reativo temporário e informação entre turnos com fonte. Cada um tem duração e autoridade distintas. |
| Fato objetivo | Valor do domínio externo cuja alteração exige autorização da aplicação proprietária. |
| Rastro de decisão | Referências a dados, versões, regras e escores que permitem inspecionar a escolha e, com a entrada autorizada, reproduzi-la. |
| AICR | Designação usada pelo SimSimi em seu serviço de conversação. O alcance documentado está na pesquisa sobre a inspiração. |
