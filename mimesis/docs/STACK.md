# Stack de referência e critérios de adoção

**Proposta de adoção.** “Base” significa que a técnica tem papel definido no primeiro produto. “Candidata” exige um experimento ou necessidade demonstrada. “Adiada” identifica uma dependência fora do caminho obrigatório. Essas classes indicam maturidade **para o MIMESIS**. A existência de uma biblioteca e de sua documentação não demonstra adequação ao corpus pt-BR ou ao equipamento alvo.

| Tecnologia | Função e maturidade no projeto | Necessidade e primeira etapa candidata |
|---|---|---|
| Python | Base para ferramenta local, compilador e experimentos. | Genesis. Escolher versão suportada em Ubuntu após teste de instalação offline. |
| SQLite, SQLite FTS5 | Base para projeção relacional local e experimento BM25. | Genesis. Verificar módulo `sqlite3` e FTS5 na distribuição escolhida. Registrar versão de biblioteca e tokenizador. [Python](https://docs.python.org/3/library/sqlite3.html) · [SQLite](https://www.sqlite.org/fts5.html) |
| DuckDB, Apache Parquet | Candidatos a consultas exploratórias e armazenamento colunar por lote. | Engenharia de dados em Research se os volumes justificarem. Manter arquivos pequenos em formatos simples. [DuckDB](https://duckdb.org/docs/stable/data/parquet/overview) · [Parquet](https://parquet.apache.org/docs/overview/) |
| RapidFuzz | Candidata a acelerar o baseline de distância. | Genesis. Fixar função, pré-processamento e escala. Comparar saídas com referência de Levenshtein. `fuzz.ratio` usa similaridade Indel e exige ensaio separado. [RapidFuzz](https://rapidfuzz.github.io/RapidFuzz/Usage/fuzz.html) |
| NumPy, SciPy | Candidatas para vetores, álgebra esparsa e análise estatística. | Lexicon, ou laboratório anterior se o experimento pedir matrizes. Registrar custo de importação e memória. |
| Scikit-learn | Candidata para TF-IDF e controles de classificação supervisionada. | Lexicon para recuperação, Sophia para modelos com rótulos revisados. Ajustar vocabulário apenas no corpus autorizado para esse fim. [Extração de atributos](https://scikit-learn.org/stable/modules/feature_extraction.html) |
| NetworkX | Candidata para protótipos de vizinhança e relações de conceitos. | Lexicon. Medir custo de materializar o grafo em memória em comparação com consultas por chave no SQLite. [NetworkX](https://networkx.org/documentation/stable/tutorial.html) |
| spaCy, NLTK | Candidatas para anotação linguística, segmentação e diagnóstico. | Pesquisa de corpus e Lexicon. Conferir separadamente licença e disponibilidade offline de cada modelo ou recurso. Amostrar prosa histórica e regional. [Modelos pt do spaCy](https://spacy.io/models/pt) · [Dados NLTK](https://www.nltk.org/data.html) |
| Polars, Pandas | Candidatas alternativas para lotes e análise tabular. | Pesquisa de dados. Medir leitura parcial, pico de RAM e facilidade de repetir operações antes de escolher uma. [Execução lazy do Polars](https://docs.pola.rs/user-guide/lazy/using/) |
| Pydantic | Candidata para validação estrita de modelos na ingestão e fronteiras. | Primeiro piloto de dados ou Genesis. Ensaio com campo ausente, tipo incompatível e custo por lote. [Modo estrito](https://docs.pydantic.dev/latest/concepts/strict_mode/) |
| Jinja2, gramáticas formais e templates procedurais | Alternativas de realização de textos já planejados. Gramática controla derivações, template preenche slots autorizados. | Mythos para descrições, Logos para composição. Medir concordância e fidelidade, limitar expansão e funções disponíveis. [Jinja](https://jinja.palletsprojects.com/en/stable/sandbox/) |
| JupyterLab, Matplotlib | Candidatas para exploração e figuras de ensaios. | Research. Notebook deve reexecutar em ordem limpa a partir de manifestos locais. Guardar dados tabulares subjacentes às figuras. |
| Streamlit | Adiada, possível interface de curadoria ou inspeção local. | Após primeiro piloto que demonstre ganho frente ao fluxo tabular. Independente do caminho de consulta. |
| Git | Base atual para histórico independente dos dois repositórios. | Research. Objetos grandes ou com limites de distribuição seguem manifesto e armazenamento autorizado. |
| uv, Pytest, Ruff | Candidatas a ambiente fixado, testes de comportamento e análise estática. | Genesis. Validar preparação offline dos pacotes, instalação limpa, teste de porta de entrada e verificações locais. [Lock e sincronização do uv](https://docs.astral.sh/uv/concepts/projects/sync/) |
| GitHub, GitHub Actions | Adiados, possíveis hospedagem e repetição das verificações locais em integração contínua. | Genesis em diante, conforme autorização para publicação e licença dos insumos. A instalação e os testes locais precisam ser independentes do serviço. [GitHub Actions](https://docs.github.com/en/actions/get-started/understand-github-actions) |
| FastAPI, REST, OpenAPI | Adiados. Adaptador HTTP e descrição do contrato, subordinados à função local. | Awakening se houver consumidor de serviço. Versionar fronteira e verificar paridade da resposta com entrada local. [FastAPI](https://fastapi.tiangolo.com/features/) |
| Sentence Transformers, embeddings, FAISS | Experimentais. Encoder gera representação, índice busca vizinhos. FAISS pode também indexar vetores de outra origem. | Pesquisa opcional desde Lexicon, sob licença, armazenamento, custo em CPU e benchmark isolado. O motor mantém caminho completo sem modelo neural. [Sentence Transformers](https://huggingface.co/sentence-transformers) · [FAISS](https://faiss.ai/) |

**Critério de promoção.** Identificar tarefa, baseline mais simples, licença dos componentes e dados, tamanho local, execução sem rede e diferença de qualidade e custo. Registrar a decisão e a combinação de versões testada. Nenhuma instalação de dependências integra esta entrega documental. [Desempenho](PERFORMANCE.md) · [Técnicas](ALGORITHMS.md)
