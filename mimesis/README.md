# MIMESIS
**Contextual Adaptive Intelligence Engine**

*Simulating intelligence through engineering, not scale.*

MIMESIS investiga quanto da interação narrativa em português brasileiro pode ser construído com repertório curado, recuperação textual, regras e composição procedural em um computador pessoal. A unidade de trabalho é uma decisão explicável sobre o que dizer diante de uma entrada e dos fatos fornecidos.

**0.0.0 · Research** entrega a especificação inicial. A primeira execução local está prevista para **0.0.1 · Genesis**. O motor é independente de aplicações. Cada sistema consumidor continua responsável pelos fatos do seu domínio.
