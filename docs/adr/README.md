# Registros de decisão arquitetural

Um ADR registra uma escolha que modifica os limites entre componentes, a autoridade de dados ou o custo de mudança do produto. Questões experimentais permanecem em [Research](../RESEARCH.md) enquanto houver apenas hipóteses.

| Registro | Estado | Base da decisão |
|---|---|---|
| [0001 · Fronteiras e autoridade](0001-BOUNDARIES.md) | Aprovada | Requisitos expressos do briefing. |
| [0002 · Projeção de conhecimento](0002-KNOWLEDGE-PROJECTION.md) | Aprovada quanto ao SQLite reproduzível. Mecânica proposta. | Requisito de reconstrução a partir de bases versionadas. |
| [0003 · Comparação em Genesis](0003-GENESIS-RETRIEVAL.md) | Proposta | Exige piloto e avaliação reservada. |

Para novo registro, escolher o próximo número disponível em coordenação com os demais agentes e incluir título, estado, contexto, decisão, alternativas consideradas, consequências, evidência e evento que exigiria revisão. Se uma decisão for substituída, preservar a anterior, apontar para a sucessora e atualizar esta tabela. A edição documental por si só não constitui aprovação de uma hipótese.
