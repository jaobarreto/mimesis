# MIMESIS Knowledge Base

A MKB reúne as fontes, revisões e condições de uso que permitem ao [motor MIMESIS](../mimesis/README.md) justificar uma resposta. Este repositório define como uma edição literária, uma expressão ou uma fala escrita pela equipe pode se tornar conhecimento liberado para um fim específico. O primeiro recorte é português brasileiro.

**Research 0.0.0** especifica o trabalho. O catálogo relaciona candidatos à coleta futura. O primeiro conjunto operacional dependerá de material autorizado, curadoria, particionamento e validação com o motor.
